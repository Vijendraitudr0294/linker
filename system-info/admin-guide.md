# Biotra — Admin Guide

## Accessing the Admin Panel
1. Log in with an admin account
2. Navigate to Dashboard → Admin (visible only to admin role users)

## Admin Capabilities

### KPI Dashboard
8 real-time metrics displayed as glass-effect cards:
- Total Users, Profile Views, Link Clicks, Orders
- Messages, Catalog Items, Catalog Views, Catalog Clicks

### Analytics Charts
- **7-Day Trend Chart** — Area chart showing views and clicks over time
- **Orders Bar Chart** — Daily order volume

### Platform Summary
Quick stats: Active Users, Blocked Users, Admin Users

### User Management
Searchable table with actions per user:

| Action | Description |
|--------|-------------|
| **Toggle Role** | Click the role badge to switch between "User" and "Admin" |
| **Block/Unblock** | Ban icon blocks user; checkmark activates |
| **Delete** | Permanently removes profile (confirmation required) |
| **View Profile** | Opens public profile in new tab |

## Promoting a User to Admin
1. Go to Admin → User Management
2. Find the user (use search bar)
3. Click the "User" badge → it changes to "Admin"

## Blocking a User
1. Find the user in the management table
2. Click the ban (🚫) icon
3. User's status changes to "Blocked"
4. Blocked users' public profiles become inaccessible

## Content Management
Content is user-managed. Admins can:
- View all user profiles via the management table
- Block inappropriate users
- Monitor platform activity via KPIs

## SEO Settings
SEO is automatic per profile:
- Dynamic `<title>` and meta description
- OpenGraph tags for social sharing
- Twitter Card meta tags
- Semantic HTML structure
